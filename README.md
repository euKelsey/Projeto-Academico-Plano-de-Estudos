# Plano de Estudos — Flutter

Projeto acadêmico desenvolvido em **Flutter e Dart** para praticar conceitos de desenvolvimento mobile, gerenciamento de estado e navegação entre telas.

O aplicativo permite acompanhar sessões de estudo, ativar um modo de foco e consultar um resumo das atividades.

## Funcionalidades

- Registro e contagem de sessões de estudo
- Opção de desfazer sessões registradas
- Ativação e desativação do modo foco
- Personalização do nome do estudante
- Visualização do resumo de estudos
- Exibição de orientações em janela modal
- Reinicialização das informações

## Conceitos trabalhados

- StatefulWidget e StatelessWidget
- Gerenciamento de estado com setState
- TextField e SwitchListTile
- Navegação com Navigator.push e Navigator.pop
- Passagem de dados entre telas
- ModalBottomSheet
- Atualização dinâmica da interface

## Tecnologias utilizadas

- Dart
- Flutter
- Material Design

**Finalidade:** projeto acadêmico desenvolvido para aplicar os conteúdos estudados na disciplina de Computação Móvel.
